# Smart Placement Portal

A beginner-friendly job board for students. This first version shows sample opportunities and lets you search them.

## Run

Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Files

- `index.html`: page content
- `styles.css`: layout and colors
- `app.js`: sample jobs and search behavior

These jobs are examples. Accounts, a database, and applications can be added in later steps.
